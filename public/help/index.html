Crucial Fix for the Blank Screen

Why Was the Page Blank at localhost/eesi/?

1. Raw Source Code vs Built Code: When you download from AI Studio, the root index.html referenced /src/main.tsx. Web browsers (Chrome, Edge, Firefox) cannot execute raw TypeScript JSX files without Vite running.

2. The Solution: We have provided a turnkey index.php at the root of the project! Because Apache automatically loads index.php first (via DirectoryIndex index.php index.html), the application will now load instantly with zero blank screens on any WAMP, XAMPP, or cPanel server!

Step-by-Step Guide

Deploying on WAMP Server

Windows
1

Create the Folder in WAMP

Open your Windows File Explorer and navigate to:

C:\wamp64\www\eesi\

(If WAMP is installed in 32-bit: C:\wamp\www\eesi\)

2

Copy All Files into the Folder

Copy the project files so index.php is directly inside C:\wamp64\www\eesi\index.php:

C:\wamp64\www\eesi\
├── index.php                      <-- Turnkey application
├── index.html                     <-- Fallback HTML
├── .htaccess                      <-- Apache rewrite rules
├── eagle_eye_quotation_system.sql <-- MySQL schema
├── favicon.png
├── assets/                        <-- Logo & media
├── api/                           <-- PHP backend API
└── config/                        <-- db.php connection config
3

Import Database into MySQL (phpMyAdmin)

Start WAMP and open: http://localhost/phpmyadmin/

  1. Click the Import tab at the top.
  2. Click Choose File and select C:\wamp64\www\eesi\eagle_eye_quotation_system.sql.
  3. Click Go. It automatically creates database eagle_eye_db and seed data!
4

Open in Your Web Browser

Go to: http://localhost/eesi/

The application will display the quotation builder, logo, and PDF export without any blank screen!

Step-by-Step Guide

Deploying on XAMPP

Win / Mac / Linux

1. Target Folder:

  • Windows: C:\xampp\htdocs\eesi\
  • macOS: /Applications/XAMPP/xamppfiles/htdocs/eesi/
  • Linux: /opt/lampp/htdocs/eesi/

2. Copy all files into that folder.

3. Start Apache and MySQL in the XAMPP Control Panel.

4. Open http://localhost/phpmyadmin/, click Import, and select eagle_eye_quotation_system.sql.

5. Open http://localhost/eesi/ in your browser.

Step-by-Step Guide

Deploying on cPanel / Live Web Hosting

cPanel / Apache / Nginx
  1. Log in to your cPanel account.
  2. Open File Manager and go to public_html (or a subdomain folder like quotations.eesecurity.com.pk).
  3. Upload the project files or zip and extract them directly into the folder.
  4. Go to MySQL Databases in cPanel:
    • Create a new database (e.g. myuser_eagleeye).
    • Create a database user, set a secure password, and grant ALL PRIVILEGES.
  5. Open phpMyAdmin in cPanel, select the new database, click Import, and upload eagle_eye_quotation_system.sql.
  6. Edit config/db.php in File Manager and enter your live database credentials:
    $db_host = 'localhost';
    $db_name = 'myuser_eagleeye';
    $db_user = 'myuser_dbuser';
    $db_pass = 'YourSecretPassword';
  7. Visit your website: https://yourdomain.com/eesi/.
